# 🎵 Simple Music Player

![Android](https://img.shields.io/badge/Platform-Android-green.svg)
![Kotlin](https://img.shields.io/badge/Language-Kotlin-purple.svg)
![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack%20Compose%20%2F%20Material3-blue.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

A modern, minimal Android music player application built with **Jetpack Compose** and **Material 3**. Features smooth full-screen player transitions, custom gradient backgrounds, and system ringtone playback via `MediaPlayer`.

一款基於 Jetpack Compose 與 Material 3 打造的現代化簡約風格 Android 音樂播放器。具備流暢的漸層視覺效果、全螢幕播放介面切換與系統預設音效播放功能。
